# Contributing

Thank you for helping improve Arabic evidence-based fact checking.

1. Open an issue describing the behavior, scientific motivation, and expected
   evidence traceability.
2. Create a focused branch and add tests for behavioral changes.
3. Run `make test` and `make lint` before opening a pull request.
4. Never commit secrets, downloaded datasets, model weights, or copyrighted
   article bodies.
5. New source-reliability mappings must be administrator-configurable and may
   not encode undocumented political judgments.

Contributions must preserve conservative abstention, source attribution, Arabic
text quality, and the separation between model confidence and evidence quality.
